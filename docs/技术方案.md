# 教师招募与家教平台技术方案

## 1. 项目概述
- **项目名称**：TeacherUp 家教平台
- **目标**：打造集用户咨询、在线对话、内容展示与后台管理于一体的轻量化平台，支持快速上线与后续扩展。
- **总体特性**：模块化、易维护、安全合规、可横向扩展。

## 2. 整体架构
- **前端**：Next.js（用户端与管理后台同仓分模块），Tailwind CSS + Ant Design。
- **API 网关**：Next.js API 路由（轻量聚合/代理）。
- **后端**：Nest.js 模块化服务（咨询、对话、轮播图、商家、认证等）。
- **数据库**：PostgreSQL 为主库，Redis 预留为缓存。
- **部署**：Nginx/CDN 前置，前后端分离部署，PM2 进程守护，支持 Docker。

## 3. 核心功能与边界
- **咨询管理**：用户提交咨询，后台可筛选、跟进、统计。
- **智能对话**：对话消息留痕，支持自动回复与人工切换（可插拔扩展）。
- **内容管理**：轮播图、商家信息配置与展示。
- **认证与权限**：JWT 无状态认证、角色可扩展。
- **运维与监控（建议）**：Sentry/Datadog，结构化日志，健康检查。

## 4. 模块清单（后端）
- 咨询（Inquiry）：CRUD、筛选、状态流转、统计。
- 对话（Conversation）：消息存储、会话分析、自动回复。
- 轮播图（Banner）：CRUD、排序、启停。
- 商家（Merchant）：基础信息、服务特色、师资优势。
- 认证（Auth）：注册、登录、令牌签发与校验、守卫。

## 5. 数据模型关系（简化）
- Inquiry（咨询）1:N Conversation（对话）
- Banner（轮播图）独立
- MerchantInfo（商家信息）独立
- Admin（管理员）独立

索引策略（节选）：
- Conversation.sessionId、Conversation.inquiryId 建索引
- Admin.username 唯一索引
- Banner.order 排序索引

## 6. 关键流程
- 咨询流程：表单校验 → DTO 验证 → Service 处理 → Prisma 入库 → 成功回执。
- 对话流程：保存用户消息 → 分析历史 → 生成回复 → 保存机器人消息 → 返回展示。
- 后台访问：JWT 认证 → 守卫校验 → 业务接口。

## 7. 安全与合规
- 账号安全：JWT、密码 Bcrypt 哈希、Token 过期（默认 7 天）。
- 数据安全：参数校验（class-validator）、类型安全（TypeScript）、ORM 参数化防 SQL 注入。
- CORS：限制合法来源与方法，支持凭据传递。
- 配置管理：敏感信息通过环境变量注入，代码库不落敏感数据。

## 8. 性能与扩展
- 前端：代码分割、图片优化（next/image）、ISR 增量静态。
- 后端：关键字段索引、查询优化、连接池，缓存层预留（Redis）。
- 网络：Gzip 压缩、CDN 静态资源加速、HTTP/2。
- 可扩展性：无状态、可水平扩容；模块化设计便于微服务拆分；消息队列可选。

## 9. 部署建议
- 开发环境：frontend:3000 → backend:3001 → PostgreSQL:5432。
- 生产建议：Nginx/CDN 前置；前端（Next.js）、后端（Nest.js）由 PM2 守护；PostgreSQL 主从复制（可选）。
- Docker：提供 compose 方案，便于快速交付与一键拉起。
