# 定时自动回复修复总结

## 修复的问题

### 1. ✅ 定时任务检查间隔问题
**问题**：检查间隔1分钟，但发送间隔30秒，可能导致长时间不发送
**修复**：
- 将检查间隔从1分钟改为每10秒一次
- 确保检查频率高于发送间隔

### 2. ✅ 定时询问顺序发送问题
**问题**：只询问了一次性别，学段没有进行询问
**修复**：
- 改进了 `getNextScheduledReply` 方法的逻辑
- 按优先级顺序发送询问（城市→学段→性别→身份→电话）
- 已填写的字段不会重复询问
- 每个询问30秒内不重复发送

### 3. ✅ 移除用户回复检查
**问题**：需要等待用户回复才发送下一个询问
**修复**：
- 移除了等待用户回复的逻辑
- 改为持续发送询问，不依赖用户回复
- 用户停留在聊天页面时持续发送询问

### 4. ✅ 人工客服隔离
**问题**：需要与人工客服回复做好隔离
**修复**：
- 添加了人工客服回复检查
- 客服回复后暂停3分钟定时询问
- 避免与人工客服冲突

## 新的工作流程

### 定时任务配置
- **检查间隔**：每10秒一次
- **发送间隔**：每个询问30秒内不重复发送
- **处理范围**：最近24小时内的活跃会话
- **限制条件**：未转人工的会话
- **人工客服暂停**：客服回复后暂停3分钟

### 智能逻辑
1. **按优先级顺序**：城市(90) → 学段(80) → 性别(70) → 身份(60) → 电话(50)
2. **已填写跳过**：已填写的字段不会重复询问
3. **防重复发送**：每个询问30秒内不重复发送
4. **人工客服隔离**：客服回复后暂停3分钟
5. **持续询问**：不等待用户回复，持续发送询问

### 测试验证
1. 用户发送消息后，10-30秒内收到城市询问
2. 继续等待30秒，收到学段询问
3. 继续等待30秒，收到性别询问
4. 用户点击选项后，该字段被标记为已填写
5. 系统继续发送下一个未填写的询问
6. 人工客服回复后，定时询问暂停3分钟

## 配置建议

在后台创建以下定时询问：

1. **城市询问**（优先级90）
2. **学段询问**（优先级80）
3. **性别询问**（优先级70）
4. **身份询问**（优先级60）
5. **电话询问**（优先级50）

每个询问设置合适的选项和字段关联，系统会自动按顺序发送。

## 注意事项

1. 确保定时询问的优先级设置正确（数字越大优先级越高）
2. 每个询问的fieldName要对应表单字段
3. 人工客服回复后会自动暂停3分钟
4. 系统会持续发送询问，直到所有字段都填写完成
